# redmine_destination_bbs_plugin  
行先掲示板プラグイン  
自分の出勤状態を登録し、自分の所属するグループメンバーの出勤状態を含めて閲覧できるようにするプラグイン

0. pluginsフォルダ内にredmine_destination_bbsフォルダ一式を配置

1. プラグインのマイグレーションを実行
bundle exec rake redmine:plugins:migrate

2. ユーザカスタムフィールド"在勤地"を作成する
※形式:リスト 複数選択:チェック無し

3. 個人設定から在勤地を選択する。  
※選択はしなくても良いが、ここで選択した値が行先掲示板に表示される。  
※在勤地を選択していた場合、7で出社を選択した際に、4の出社場所と一致するものだった場合、自動的に出社場所も登録してくれる。

4. 管理メニューから出社場所リスト(行先掲示板プラグイン)を選択し、任意の出社場所を追加/保存する。

5. グループにユーザーを登録する。

6. トップメニューの行先掲示板からページへ遷移できる。

7. 「在宅」「出社」「出張」などから選択する。

8. 行先と開始時刻が登録される。  
※開始時刻はボタンを押下した時間で更新される。  
※体調と体温はデフォルトで「良好」「平熱」となる。変更する場合は体調欄や体温入力欄を更新したうえで「体調情報更新」ボタンを押下する。  
※何かコメントを残す場合はコメント入力欄に記入した状態で「コメント更新」ボタンを押下する。  

9. 退勤時には「退勤」ボタンを押下する。  
※退勤ボタンを押下したタイミングで終了時刻が記録される。


動作確認環境(v0.8.0):  
Windows11  
Redmine 7.0.1  
Ruby 3.4.10-p104 (2026-06-30) [x64-mingw-ucrt]  
Rails 8.1.3.1  
Mysql 8.4.11
